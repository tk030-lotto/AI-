# 躊躇してないで、とにかく作ってみよう。

## AI開発アシスタント (Web Application)

> **「AIで作ってみたいなら、まず一個作ってみよう。」**

本ツールは、AIを使ったソフトウェア開発に興味がある人が、専門知識や事前の勉強なしに「こんなの作って」から最初の一歩を踏み出すための無料Webアプリケーションです。

---

## 1. 特徴とコンセプト

- **細かな仕様作成は不要**: 「こんなの作って」というアイデアを入力するだけで、AIが要件定義を行い、開発に必要な `README.md` と `仕様書.md` を自動生成します。
- **スマートフォン ＋ PC の2画面構成**:
  - **スマートフォン**: 本ツールを開き、手順確認・プロンプト生成・文書確認のガイド（2画面目）として利用。
  - **PC**: Google Antigravity IDE を起動し、実際のコーディング・開発を実行。
- **Zero-Dependency & 高速動作**: 外部ライブラリに依存しない Pure HTML/CSS/JS 構成。
- **LocalStorage 状態保持**: ブラウザを閉じても入力内容と進行状況が保持されます。

---

## 2. 使い方（9ステップ）

1. **ようこそ**: コンセプトを確認してスタート。
2. **IDE準備**: PCで Google Antigravity IDE をインストール・起動（無料枠で試せます）。
3. **作りたいものを入力**: 「こんなの作って」を自由入力、または4つの実用サンプルから選択。
4. **AIへ依頼文送信**: 生成された依頼文をワンタップでコピーし、Antigravity IDE のチャット欄に貼り付け。
5. **AI質問待機**: AIからの確認事項に回答（なければ自動で整理が進みます）。
6. **文書確認**: Antigravity IDE 上で作成された `README.md` / `仕様書.md` を確認。
7. **判定**: 「これで作る（開発開始）」または「修正する」を選択。
8. **修正依頼**: 修正したい点があれば、追加の修正指示文を生成してAIに送信。
9. **開発開始**: Antigravity IDE で実装を開始！
